# EDITFORGE Studio 3.0

Studio do ćwiczenia i tworzenia editów **Gaming / Anime AMV / Creative / Cyberpunk**. Prototyp aplikacji webowej i desktopowej.

## Uruchomienie na komputerze
- Otwórz `index.html` w nowoczesnej przeglądarce.
- Aplikacja desktopowa: `npm install` i `npm start` (wymagany Node.js).
- Windows portable: `npm run pack:win`.

## iPhone
Po publikacji pod HTTPS otwórz stronę w Safari i wybierz Udostępnij → Dodaj do ekranu początkowego.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`. Na darmowym planie GitHub Pages może wymagać publicznego repozytorium. **Nie zmieniaj widoczności, jeśli kod ma pozostać prywatny**. Alternatywnie użyj Netlify lub Vercel.

## Ważne
To prototyp: nie wszystkie narzędzia są odpowiednikami pełnego CapCut. Eksport i obsługa multimediów zależą od możliwości przeglądarki. Nie umieszczaj prywatnych klipów ani sekretów w publicznym repozytorium.
